# BDML Coursework Portfolio | Reg no: 241501185

This repository contains the BDML experiment portfolio and an original, reproducible mini project prepared for registration number **241501185**.

## Mini project

**Smart Urban Water Demand Forecasting with Machine Learning** demonstrates supervised regression on a deterministic synthetic daily dataset. The report includes problem framing, features, chronological train/test evaluation, a mean baseline, ordinary least squares, ridge regression, results, figures, limitations, and reproducibility instructions.

> The dataset is synthetic, not measured utility data. Performance results validate the workflow only and must not be presented as real-world utility performance.

Open `BDML_Mini_Project_241501185.pdf` for the polished report, `mini_project/data/urban_water_demand.csv` for data, and `mini_project/run_analysis.py` for the analysis. Run from `mini_project/`:

```bash
python -m pip install -r requirements.txt
python run_analysis.py
```
